# Миграция формата переходов MetaFor

## Выполненная работа

Успешно удалена поддержка старого массивного формата переходов в пользу нового объектного формата.

## Изменения в формате

### Старый формат (удален)
```javascript
to: [{state: "next", when: {condition: true}}]
```

### Новый формат (единственный поддерживаемый)
```javascript
to: {"next": {condition: true}}
```

## Ключевые преимущества нового формата

1. **Лучшая автокомплетация TypeScript** - состояния теперь являются ключами объекта
2. **Более читаемый код** - состояния видны сразу в структуре объекта
3. **Упрощенная логика** - нет необходимости поддерживать два формата
4. **Консистентность** - единый подход во всей кодовой базе

## Совместимость

⚠️ **ВАЖНО**: Старый массивный формат больше НЕ ПОДДЕРЖИВАЕТСЯ. Все переходы должны использовать новый объектный формат.

## Примеры миграции

### Простой переход
```javascript
// Старый формат
to: [{state: "ready", when: {loaded: true}}]

// Новый формат  
to: {"ready": {loaded: true}}
```

### Множественные переходы
```javascript
// Старый формат
to: [
  {state: "success", when: {error: null}},
  {state: "error", when: {error: {isNull: false}}}
]

// Новый формат
to: {
  "success": {error: null},
  "error": {error: {isNull: false}}
}
```

### Пустые переходы
```javascript
// Старый формат
to: []

// Новый формат
to: {}
```
